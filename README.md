# Veldbrein — Sunville Tigers

Honkbal-tactiektrainer voor de U12 van de Sunville Tigers (Zonhoven): spelers oefenen
razendsnel waar ze de bal naartoe gooien.

**Spelen:** https://sunvilletigers.github.io/veldbrein/
(op gsm of tablet: open de link en kies "Toevoegen aan beginscherm" om hem als app te installeren).

Deze repo bevat enkel de speelbestanden. Op het online scorebord staan alleen een
bijnaam, een rugnummer, punten en level — geen echte namen, geen e-mail, geen reclame
of tracking.
